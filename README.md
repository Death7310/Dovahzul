# Dragon language research and design workspace

**Unofficial fan project.** Not affiliated with, endorsed or sponsored by Bethesda Softworks, ZeniMax Media or Microsoft. The Elder Scrolls and Skyrim are trademarks of ZeniMax Media Inc. Dragon-language text from the games belongs to its owners and is quoted here for study and commentary.

This repository holds research and a design proposal for a free, offline app that would teach the dragon language of *The Elder Scrolls V: Skyrim* and extend it under published rules. No app exists yet.

## What is here

| Path | Contents |
|---|---|
| `docs/design-proposal.md` | The design proposal, awaiting the owner's decisions |
| `research/01` to `15` | Research reports, each with a checked reference list in `research/refs/` |
| `research/data/` | Data extracted from the wiki snapshot; see its `README.md` |
| `research/sources/uesp/` | The wiki snapshot the data was built from; see `ATTRIBUTION.md` there |
| `tools/` | Scripts that fetch, parse, check and analyse the data |
